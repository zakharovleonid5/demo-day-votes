# Demo Day Voting MVP

Легкая голосовалка для демо-дня: мобильная страница жюри и кабинет организатора.

## Запуск локально

```bash
cd demo_day_voting
$env:ADMIN_PASSWORD="demo-admin"
npm start
```

- Голосование: http://localhost:3100/
- Админка: http://localhost:3100/admin

Данные лежат в `data/db.json`. Для продакшена задайте `ADMIN_PASSWORD`, `PORT` и при необходимости `DATA_FILE`.

## Что есть в MVP

- организатор добавляет выступления;
- организатор выбирает активное выступление или открывает все;
- жюри голосует с телефона по 4 критериям со шкалой 0-5;
- оценки можно обновлять;
- админка показывает число оценок, лидерборд, средний балл и матрицу “кто кому что поставил”.

## Оценка сервера

Для 20-100 голосующих достаточно самого маленького VPS:

- 1 vCPU;
- 512 MB RAM, лучше 1 GB RAM с запасом;
- 5-10 GB SSD;
- Node.js 20+;
- HTTPS через nginx/Caddy.

Даже 100 человек, 20 выступлений и 4 критерия дадут примерно 2 000 оценочных строк. JSON-база займет меньше нескольких мегабайт. Основной запас нужен не под данные, а под ОС, Node.js, логи и деплой.
